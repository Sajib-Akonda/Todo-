# JavaScript To-Do List

A simple and beginner-friendly **To-Do List web application** built with **HTML, CSS, and JavaScript**.

This project was created to practice JavaScript fundamentals such as arrays, objects, DOM manipulation, event listeners, functions, and dynamic rendering.

## Features

- Add new tasks
- Add a due date to each task
- Display tasks dynamically
- Delete tasks
- Automatically update the task list
- Clear input fields after adding a task

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**

## JavaScript Concepts Practiced

While building this project, I practiced:
